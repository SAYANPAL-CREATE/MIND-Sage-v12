# Deployment checklist

- [ ] Use a **new repository** for testing, leaving your previous Mind-sage version available.
- [ ] Upload every file from the ZIP into the repository root; `index.html` must be at root.
- [ ] Enable GitHub Pages: Settings > Pages > Deploy from branch > `main` > `/(root)`.
- [ ] Confirm the home page, stage-selection buttons and the Guardian Care page.
- [ ] Complete one adult questionnaire and download a report containing the supplied name and age.
- [ ] Complete one primary-school guardian flow and verify the guardian respondent in the report.
- [ ] Check the Vani portrait, the Contact Us images, and video links.
- [ ] Test English/Bengali switching, keyboard focus, and narrow-mobile menu.
- [ ] Review browser site-data settings and old offline caches before replacing an active site.
- [ ] Never put private API keys or research-participant records into a public GitHub Pages repository.
